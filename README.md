# ASTRION

### An Interactive 3D Space Exploration Game

**Developed by Team Zenith Horizon**

ASTRION is a browser-based 3D space exploration game that lets players experience spaceflight, explore celestial environments, and undertake exploration missions.

The project combines interactive gameplay, 3D environments, spacecraft models, and scientific visual resources to create an immersive space exploration experience.

## Features

- 3D space environment featuring Earth, Moon, and outer space.
- Spacecraft launch and flight sequences.
- Cockpit and external camera perspectives.
- Moon approach and landing.
- Lunar exploration and sample collection.
- In-game photography.
- Asteroid encounter and avoidance gameplay.
- NASA-based scientific references and asteroid information.
- Responsive controls for supported desktop and touch devices.

## Installation

### Requirements

- Node.js 20.19+ or 22.12+
- npm
- A modern browser with WebGL support

### Setup

Clone the repository:

```bash
git clone https://github.com/sunainamir/ASTRION.git
```

Open the project directory:

```bash
cd astrion
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in your terminal.

## Build and Production

Check the code:

```bash
npm run lint
```

Build the application:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

## Scientific Resources

ASTRION uses selected NASA imagery, planetary textures, 3D resources, and scientific references.

NASA's Near Earth Object Web Service (NeoWs) may also be used for asteroid-related information.
