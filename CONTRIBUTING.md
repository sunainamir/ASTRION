# Contributing to ASTRION

Thank you for your interest in ASTRION.

We welcome suggestions, bug reports, and improvements.

## How to Contribute

1. Fork the repository.
2. Create a branch for your changes.
3. Make focused improvements.
4. Test your changes locally.
5. Submit a pull request with a clear description.

## Development Checks

Run:

```bash
npm run lint
npm run build
```

## Guidelines

- Follow the existing project structure.
- Keep code readable and maintainable.
- Avoid unnecessary dependencies.
- Consider performance on different devices.
- Never commit API keys or private credentials.
- Only include third-party assets when their licenses permit the intended use.

## Asset Contributions

When adding external assets, document:

- Creator
- Source URL
- License
- Attribution requirements
- Any modifications

Update `CREDITS.md` and `THIRD_PARTY_NOTICES.md` accordingly.

Thank you for helping improve ASTRION!
