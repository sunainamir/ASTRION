# Security Policy

## Reporting Security Issues

Please do not publish sensitive security vulnerabilities or credentials in public issues.

If you discover a vulnerability, report it privately to the repository maintainers through an available private GitHub reporting channel or contact method.

Include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation, if available

## Protecting Secrets

- Never commit `.env` files.
- Never publish API keys or access tokens.
- Keep server-side API credentials private.
- Use environment variables for secrets.
- Rotate credentials if they are accidentally exposed.

Security is important to the reliability and safety of ASTRION.
